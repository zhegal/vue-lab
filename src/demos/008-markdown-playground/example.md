# Markdown playground

Edit this document to update the preview.

## Text and links

Try **bold**, _emphasis_, ~~strikethrough~~ and `inline code`.

[Markdown syntax](https://commonmark.org/help/) opens in a new tab.

> A quote can contain **formatted text**.

## Lists and tables

1. Edit the source.
2. Switch between Source, Split and Preview.
3. Open a local `.md` file.

| Feature  | Behavior            |
| -------- | ------------------- |
| Preview  | Updates as you type |
| Files    | Read locally        |
| Raw HTML | Displayed as text   |
